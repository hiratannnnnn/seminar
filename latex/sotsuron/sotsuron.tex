\chapter*{論文要旨}
\addcontentsline{toc}{chapter}{論文要旨}

生物学において進化の過程を論じる際，
突然変異を経て変化する世代間の影響を考慮することは不可欠である．
また，生物学的背景から発生しやすい変異と
そうでない変異を区別し，前者を中心に
遺伝的な距離を定義し，考察することは自然なアプローチと言える．

HannenhalliおよびPevzner (1995)\cite{hp1995}は，
染色体に作用する操作を「転座」「融合」「分裂」「反転」
の4種類に制限し，遺伝的距離 $d_{\mathrm{HP}}$
を定義した．しかしながら，この手法および提案された
アルゴリズムには，計算上の制約や複雑性に関する課題が存在した．

Bergeronら (2009)\cite{bergeron2009}は，これらの問題を解決すべく，
上記4種類の操作を一般化した「Double-Cut-And-Join（以下，DCJ）
という単一の操作を導入し，新たなアルゴリズムを提案した．
DCJ操作に基づく距離を $d_{\mathrm{DCJ}}$ と呼ぶ．

Bergeronらの手法は，染色体内の特定パターンを検出することで
線形時間での操作手順出力を可能にしているが，その実装は
高度であり，直感的な理解が困難な側面がある．
本論文では，DCJ理論におけるBergeronらと同様の前提条件の下，
C言語を用いたより簡潔な線形時間アルゴリズムの実装について述べる．
本稿の前半では $d_{\mathrm{DCJ}}$ の算出に特化したアルゴリズムを，
後半では操作手順も出力する，より汎用性の高いシンプルな実装を紹介する．

実装においては，一部の着想をBergeronら(2009)の研究に依拠しつつも，
主要なデータ構造および処理ロジックの大部分は独自に構築したものである．

\chapter{導入}

\section{背景}
計算分子生物学において遺伝的距離をモデル化する手法には
多くの変遷があるが，その基本的な枠組みは共通している．
単純性の原理（Principle of Parsimony）のもとでは，
可能な限り小さい回数の変化を知ることが重要になる．つまり，
最終的な目標は，二つのゲノム間の最小変異回数を算出し，
それらを比較・評価することになる．

\section{ゲノムおよび染色体の表現方法}
比較対象となる二つのゲノムを，それぞれ
\textit{source} および
\textit{target} と呼ぶ．
各ゲノムは染色体（chromosome）の集合であり，
各染色体は遺伝子（gene）の並びである．

各遺伝子は正負の符号を持つ整数値で識別する．
向きの基準を \textit{target} ゲノムに置き，
絶対値の対応づけは任意であるため， \textit{target}
が昇べきの順となるようにつける．すなわち，
遺伝子数 $n$ のゲノムにおいて，\textit{target}
が単一の線形染色体である場合，その表現は常に
$\langle 1, \ 2, \ \dots, \ n \rangle$
と一意に定まる．線形染色体と環状染色体を区別するため，
本論文では以下の表記を用いる．
\begin{itemize}
    \item \textbf{線形染色体}: $\langle \dots \rangle$ で囲む．
    \item \textbf{環状染色体}: $( \dots )$ で囲む．
\end{itemize}

\begin{remark}
環状染色体 $( 5, \ 6, \ 7 )$ は，
要素を巡回させた $( 6, \ 7, \ 5 )$ や
 $( 7, \ 5, \ 6 )$ と同一である．
\end{remark}

\section{端点（extremity）と隣接（adjacency）}
アルゴリズムの実装においては，
遺伝子間の「接続関係」を直接扱う方が効率的である．
遺伝子 $g$ に対し，二つの \textbf{端点（extremity）}
 を，右側の端点 $g$ および左側の端点 $-g$ と定義する．
 二つの遺伝子の接続は，これら端点の2要素の集合として表現され，
 これを \textbf{隣接（adjacency）} と呼ぶ．
すなわち，右側の端点は遺伝子の符号を継承し，
左側の端点はその逆符号を持つ．

また，線形染色体の末端については，
特殊なシンボル $o$ を用いて
\textbf{テロメア（Telomere）}\footnote{生物学において染色体の末端を保護する構造体に由来する名称である．}
との接続 $\{o, x\}$ として扱う．この定義により，
ゲノムは単なる隣接関係の集合として記述でき，
線形・環状の区別や染色体数を意識せずに
統合的な操作が可能となる．

なお，実装上の細かな差異について付記すると，
\textbf{adjacency} は2つの \textbf{extremity}
から構成されるため，
いずれのアルゴリズムでも基礎的なデータとして
\textbf{extremity} が必要となるが，
主な操作対象には違いがある．
第3章のアルゴリズム1（距離計算）では隣接グラフの構造を調べるため、
\textbf{adjacency} の走査が行われるが，
第4章のアルゴリズム2（操作手順出力）では接続替えの操作を行うため
\textbf{extremity} を直接操作する．

本研究での実装において，これらの概念は以下の構造体として定義される．

\begin{lstlisting}[caption=extremity 構造体の定義, label=code:extremity]
typedef struct extremity
{
    int id;                     // 遺伝子ID (1 ...)
    int sign;                   // 向き (1 or -1)
    struct extremity *reality;  // ゲノムAにおける接続先
    struct extremity *desire;   // ゲノムBにおける接続先
} extremity;
\end{lstlisting}

\begin{lstlisting}[caption=adjacency 構造体の定義, label=code:adjacency]
typedef struct adjacency
{
    extremity *left;            // 隣接の左端点
    extremity *right;           // 隣接の右端点
    struct adjacency *left_to;  // グラフ上の左側エッジ
    struct adjacency *right_to; // グラフ上の右側エッジ
    int visited;                // 探索用フラグ
} adjacency;
\end{lstlisting}

\chapter{理論的背景}

\section{$d_{\mathrm{DCJ}}$に関する等式}

Bergeronら(2006)\cite{bergeron2006}は，
DCJ操作を用いたゲノム距離の計算において，
以下の重要な定義および定理を示している．

\begin{definition}[Double-Cut-And-Join]
ゲノムの隣接関係の集合に対する操作であり，
二つの隣接 $\{u, v\}$ と $\{x, y\}$ を切断し，
新たに $\{u, x\}$ と $\{v, y\}$ ,
または $\{u, y\}$ と $\{v, x\}$
として再結合する操作を指す．
テロメア $o$ を含む隣接に対しても同様に定義される．

また，$\{o, o\}$ とのDCJも認めることで，
単なる隣接の切断もDCJに含めるものとする．
\end{definition}

\begin{definition}[隣接グラフ $AG(A,B)$]\label{def:adj_graph}
2つのゲノム $A, B$ において，
それぞれの隣接関係およびテロメアを頂点集合とし，
共通の遺伝子端を持つ頂点間にエッジを引いたグラフを
隣接グラフと呼ぶ．

ただし，共通の要素がテロメア $o$ である
場合はエッジを引かないものとする．
また，2つの頂点間で2つの遺伝子端が共通する場合，
それぞれの端点に対応する計2本のエッジを引くこととする．
したがって，隣接グラフは多重グラフとなり得る．
\end{definition}

\begin{remark}
それぞれの頂点の次数は高々2であるため，隣接グラフは
サイクル（Cycle）とパス（Path）のみからなる．
\end{remark}

\begin{example}
以下のゲノム $A, B$ を考える （$N=5$）．
\begin{verbatim}
A: < 1 -4 > ( 3 -2 ) < 5 >
B: < 1 2 3 > ( 4 5 )
\end{verbatim}

これらのゲノムは， 以下のような隣接の集合としても表現できる．
\[
    A = \{ \{ o, -1 \}, \{ 1, 4 \}, \{ -4, o \}, \{ 3, 2 \}, \{ -2, -3 \}, \{ o, -5 \}, \{ 5, o \} \}
\]
\[
    B = \{ \{ o, -1 \}, \{ 1, -2 \}, \{ 2, -3 \}, \{ 3, o \}, \{ 4, -5 \}, \{ 5, -4 \} \}
\]

また， これらに基づく隣接グラフ（定義\ref{def:adj_graph}参照）の成分は以下のようになる（円形のノードは， 青色がゲノム $A$ の隣接， 赤色がゲノム $B$ の隣接を表す）．

\end{example}

\begin{lemma}[成分数の変化]
\label{lem:comp_change}
隣接グラフG(A, B)に対する1回のDCJ操作により，
連結成分（サイクルまたはパス）の総数は最大で1つ増減する．
\end{lemma}

\begin{proof}
DCJ操作は，グラフ上の高々2つの頂点に対して行われる局所的なつなぎ替えである．
操作対象となる頂点が属する連結成分（コンポーネント）の種類（パスまたはサイクル）とその数によって，
以下の全てのケースに分類できる．それぞれのケースにおける成分数の変化量 $\Delta$ を列挙する．

\begin{enumerate}
\item \textbf{パスのみに関わる操作}（図\ref{fig:dcj_paths}）\\
2つのパス間，あるいは1つのパス内での操作．
\begin{itemize}
    \item (a) 2つのパスの末端または内部をつなぎ替えるケース: 異なるパス間での交換が起きるが，成分数は不変 ($\Delta=0$)．
    \item (b) 2つのパスを結合して1つのパスにするケース: 成分数は1減少 ($\Delta=-1$)．
    \item (c) 1つのパスを切断して2つのパスにするケース: 成分数は1増加 ($\Delta=+1$)．
\end{itemize}

パスとサイクル間，あるいはパスがサイクルを生じる（吸収する）操作．
\begin{itemize}
    \item (a) パスから一部を切り出しサイクルとする，あるいは逆にサイクルをパスの一部に組み込むケース: 成分数は1増減 ($\Delta=\pm 1$)．

    \item (c) パス内の一部の向きを反転させるケース: 成分数は不変 ($\Delta=0$)．
\end{itemize}

\begin{itemize}
    \item (a) 2つのサイクルを結合する，あるいは1つのサイクルを分割するケース: 成分数は1増減 ($\Delta=\pm 1$)．
    \item (b) サイクル内の一部の向きを反転させるケース: 成分数は不変 ($\Delta=0$)．
\end{itemize}

\end{proof}

\begin{lemma}[奇数長パス数の変化]
\label{lem:odd_path_change}
隣接グラフにおいて，1回のDCJ操作は奇数長パスの数 $I$ を 2 増加，変化なし，あるいは 2 減少させる．
\end{lemma}

\begin{proof}
本隣接グラフは，ゲノムAの頂点とゲノムBの頂点の間にエッジを持つ二部グラフである．
したがって，パスの長さの偶奇性は両端点の所属によって以下のように定まる．
\begin{itemize}
    \item \textbf{奇数長パス}: 両端点が異なるゲノムに属する．
    \item \textbf{偶数長パス}: 両端点が同じゲノムに属する．
\end{itemize}
DCJ操作は単一のゲノム内の隣接関係に対して作用するため，操作に関与する頂点は同一のゲノムに属する．
一般性を失わず，ゲノムAに対して操作を行うものとする．

\paragraph{1. パス同士の結合・分割（1-b, 1-c）}
2つのパスを結合する場合，結合点となる2つの端点は共にゲノムAに属する．各パスのもう一方の端点をそれぞれ$x, y$とすると，結合後の新たなパスの両端点は$x, y$となる．
\begin{enumerate}
    \item \textbf{2つの奇数長パスの結合}:
    結合前のパスは奇数長であるため，$x$および$y$は共にゲノムBに属する．
    結合後のパスは両端点$x, y$が共にゲノムBに属するため，偶数長となる．
    したがって，奇数長パスは2つ減少し，偶数長パスが1つ増加するため，$\Delta I = -2$．
    \item \textbf{2つの偶数長パスの結合}:
    結合前のパスは偶数長であるため，$x$および$y$は共にゲノムAに属する．
    結合後のパスは両端点が共にゲノムAに属するため，偶数長となる．
    したがって，$\Delta I = 0$．
    \item \textbf{奇数長パスと偶数長パスの結合}:
    一方の端点はゲノムBに，もう一方はゲノムAに属する．
    結合後のパスの両端点は異なるゲノムに属するため，奇数長となる．
    したがって，奇数長パスの総数は変わらないため，$\Delta I = 0$．
\end{enumerate}
1つのパスを2つに分割する操作（1-c）は上記結合操作の逆であり，$\Delta I$ は$2, 0, 0$のいずれかとなる．

\paragraph{2. パスとサイクルの操作（2-a, 2-b, 2-c）}
\begin{enumerate}
    \item \textbf{パスからのサイクルの切り出し・組込み（2-a）}:
    パスの内部で自己交差的に接続を組み替えてサイクルを分離する場合，残ったパスの両端点は変更されない．したがってパスの長さの偶奇性も維持され，$\Delta I = 0$．
    \item \textbf{パスの閉路化・サイクルの開路（2-b）}:
    パスの両端を結合してサイクルにするには，両端が同じゲノム（A）に属する必要がある．これは偶数長パスに対してのみ可能であり，このとき偶数長パスが1つ減少しサイクルが増える．奇数長パスの数$I$には影響しない（$\Delta I = 0$）．
    \item \textbf{パス内部の反転（2-c）}:
    パスの両端点は不変であるため，$\Delta I = 0$．
\end{enumerate}

\paragraph{3. サイクルのみの操作（3-a, 3-b）}
サイクルのみに関わる操作においてはパスは関与しないため，奇数長パスの数は変化しない（$\Delta I = 0$）．

以上より，いずれのケースにおいても奇数長パスの数 $I$ の変化量は偶数（$-2, 0, 2$）に限られる．
\end{proof}

\begin{lemma}[ゲノムの一致条件]
\label{lem:identity}
$N$ 個の遺伝子集合からなるゲノム $A, B$ が
$A=B$ であるための必要十分条件は，
次式が成り立つことである：


\begin{equation}
    N = C + \frac{I}{2}
\end{equation}
ここで，$C$ は隣接グラフ $AG(A,B)$
におけるサイクルの数，$I$ は奇数長パス
（辺の数が奇数のパス）の数である．
\end{lemma}

\begin{proof}
ゲノム $A$ における隣接の数を $a$，テロメアの数を $t$ とおくと，遺伝子の総数は $N = a + t/2$ と表される．

まず必要性 ($A=B \implies N = C + I/2$) を示す．
$A$ と $B$ が同一であれば，任意の隣接 $\{u, v\} \in A$ は $B$ における同一の隣接と，共有する2つの遺伝子端を介して2重に結合されるため，長さ2のサイクルを形成する．したがって，サイクルの総数は $C=a$ となる．
同様に，各テロメア $\{u\} \in A$ は $B$ の対応するテロメアと単一のエッジで結ばれ，長さ1のパス（奇数長パス）となることから，$I=t$ が従う．
ゆえに，$C + I/2 = a + t/2 = N$ が成立する．

次に十分性 ($N = C + I/2 \implies A=B$) を示す．
隣接グラフにおけ辺の総数に着目する．各遺伝子は2つの端点を持ち，これらがゲノム $A$ および $B$ の頂点間で共有されるため，グラフ全体のエッジ数は $2N$ 本となる．
また，本グラフは二部グラフであることから奇数長サイクルは存在せず，頂点の次数が高々2であることから偶数長パスも構成され得ない．

仮定より $2N = 2C + I$ が成り立つが，これはグラフ内の全エッジがサイクルまたは奇数長パスのみによって構成されていることを意味する．
ここで，サイクルの最小長は2，奇数長パスの最小長は1である．
エッジ総数の制約と等式 $2C + I = 2N$ を考慮すれば，$C$ 個のサイクルはすべて長さ2であり，$I$ 本のパスはすべて長さ1でなければならないことが導かれる．

長さ2のサイクルはテロメアを含まない隣接関係の一致を，長さ1のパスはテロメアの一致をそれぞれ意味する．
以上より，全ての隣接関係およびテロメアが完全に一致するため，$A=B$ が示された．
\end{proof}

\begin{lemma}[DCJ距離の下限]
\label{lem:lower_bound}
任意の2つのゲノム $A, B$ について，DCJ距離は以下を満たす：


\begin{equation}
    d_{\mathrm{DCJ}}(A,B) \ge N - \left( C + \frac{I}{2} \right)
\end{equation}
\end{lemma}

\begin{proof}
補題\ref{lem:comp_change}および補題\ref{lem:odd_path_change}より，
1回のDCJ操作でサイクル数 $C$ と奇数長パス数 $I$ が同時に変化することはない．
したがって，量 $C + I/2$ の1操作あたりの増加量は最大でも $1$ である（$C$ が1増えるか，$I$ が2増える場合）．
目標状態では補題\ref{lem:identity}より $N = C + I/2$ であるため，初期状態からの差分を埋めるために少なくとも右辺の回数の操作が必要となる．
\end{proof}

\begin{theorem}[DCJ距離公式]
2つのゲノム $A, B$ 間の最短のDCJ操作回数（DCJ距離）
$d_{\mathrm{DCJ}}(A,B)$ は，次式で与えられる：
\begin{equation}
    d_{\mathrm{DCJ}}(A,B) = N - \left( C + \frac{I}{2} \right)
\end{equation}
この距離を達成する最短の並べ替え手順は，
線形時間 $O(N)$ で計算可能である．
\end{theorem}

\begin{proof}
補題\ref{lem:lower_bound} により下限が示されているため，この回数でソートを行う手順が存在することを示せばよい．
まず，$A \neq B$ である限り，$B$ に存在して $A$ に存在しない隣接（2つの端点の接続），あるいはテロメアとの接続が必ず存在する（$A$ と $B$ が一致せず，かつこれら全てが一致している状況は存在しない）．
第4章で詳述する貪欲法アルゴリズムは，そのような不一致箇所を解消するように操作を行うことで，
常に $C + I/2$ を $1$ ずつ増加させる操作（$C$ を1つ増加させる，あるいは $I$ を2つ増加させる操作）を選択し続けることができる．
したがって，下限値でのソートが可能であり，これが最短距離となる．
\end{proof}

\section{距離公式に関する考察}
(2.3)式は，$d_{\mathrm{DCJ}}$を計算する上で，
隣接グラフの初期状態さえ構築できれば，
実際にグラフを物理的に変形させる手順を踏まずとも，
グラフ内のコンポーネント（サイクルおよびパス）を走査し
$C, I$ を計数するだけで距離が確定することを示している．
この知見に基づき，まずアルゴリズム1を提案する．

% --- 第3章：アルゴリズム1 ---


\chapter{アルゴリズム1：距離計算の実装}

本アルゴリズムは，隣接グラフを構築し，
そこに含まれるサイクルおよび奇数長パスを線形時間で探索するものである．

\section{入力形式}
本実装では，以下のフォーマットに従うテキストファイルを入力とする．
1行目に遺伝子数 $N$，2行目にゲノム $A$，3行目にゲノム $B$ を記述する．

\begin{verbatim}
5
< 1 -4 > ( 3 -2 ) < 5 >
< 1 2 3 > ( 4 5 )
\end{verbatim}

ここで \texttt{< ... >} は線形染色体，\texttt{( ... )} は環状染色体を表し，
内部の数字は遺伝子IDおよびその符号（向き）を示す．

\section{データ構造}
実装においては，以下の3つの要素を中核とする．
\begin{itemize}
    \item \textbf{extremity}: 遺伝子の端点を表す構造体．IDと符号を保持する．
    \item \textbf{adjacency}: 2つの extremity のペア．探索を効率化するため，各隣接が $source$ と $toget$ のどちらに属するか，および訪問済みかどうかのフラグを持つ．
    \item \textbf{Map}: 特定の端点がどの adjacency に含まれているかを定数時間で検索するための整数値配列．
\end{itemize}

これらのデータ構造は，以下の手順によって入力から構築される．

\begin{algorithm}[H]
    \caption{入力からのデータ構造構築}
    \KwIn{入力ファイル}
    \KwOut{EXT配列（extremity集合）, ADJリスト（adjacency集合）}

    $N \leftarrow$ 1行目から読み込む\;
    $EXT \leftarrow$ サイズ $2N$ の配列を初期化\;

    \tcp{ゲノムAの処理}
    2行目をパースし，Aの構成を取得\;
    \ForEach{Aにおける隣接 $\{u, v\}$}{
        $u, v$ に対応する $EXT$ 内要素のポインタを相互に接続 (reality)\;
        $ADJ\_NODE \leftarrow$ $u, v$ を持つ新規 adjacency ノード\;
        $ADJ$ リストに追加\;
    }
    \tcp{ゲノムBの処理}
    3行目をパースし，Bの構成を取得\;
    \ForEach{Bにおける隣接 $\{x, y\}$}{
        $ADJ$ リスト内の，$x$ を含むノードと $y$ を含むノードを探索\;
        発見したノード間にエッジ（$left\_to$ / $right\_to$）を張る\;
    }
    \Return $EXT, ADJ$\;
\end{algorithm}

\begin{algorithm}[H]
    \caption{隣接グラフを用いたDCJ距離の計算}
    \KwIn{ゲノム $A$, ゲノム $B$}
    \KwOut{DCJ距離 $d_{\mathrm{DCJ}}$}

    $N \leftarrow$ 遺伝子数\;
    $AG(A, B) \leftarrow$ $A$ と $B$ の隣接集合から隣接グラフを構築\;
    $C \leftarrow 0$, $I \leftarrow 0$\;

    \ForEach{未訪問の隣接ノード $v \in AG(A, B)$}{
        $v$ から始まるコンポーネントをトラバースする\;
        $L \leftarrow$ トラバースしたエッジ（隣接関係）の総数\;
        \If{探索が開始点に戻った（サイクルを発見）}{
            $C \leftarrow C + 1$\;
        }
        \ElseIf{端（テロメア）に到達した（パスを発見）}{
            \If{$L$ が奇数}{
                $I \leftarrow I + 1$\;
            }
        }
    }
    $d_{\mathrm{DCJ}} = N - (C + I/2)$\;
    \Return $d_{\mathrm{DCJ}}$\;
\end{algorithm}

\section{正当性と計算量}
本アルゴリズムの探索部分は，
各エッジをちょうど一度ずつ走査するため，
計算量は $O(N)$ となる．
終了性については，
各 adjacency に訪問済みフラグを設定し，
一度の走査で全コンポーネントを網羅するため，
有限時間内での停止が保証される．

% --- 第4章：アルゴリズム2 ---


\chapter{アルゴリズム2：操作手順の出力}

\cite{bergeron2006} の理論を基に，
実際の変異手順を逐次的に出力するアルゴリズムを実装した．

\section{実装方針}
本アルゴリズムでは，
現在のゲノム状態を目標のゲノム状態へ貪欲法により近づけていく．
具体的には，特定の接続が目標とする接続となっていない場合，
DCJ操作を適用してその接続を確立させていく．

\begin{algorithm}[H]
    \caption{DCJ操作によるゲノムソート手順の生成}
    \label{alg:proceed}
    \KwIn{現在のゲノム $A$ の端点集合 $exts$, 目標状態 $goals$}
    \KwOut{実行されたDCJ操作のログ}

    $n \leftarrow$ 遺伝子数, $c \leftarrow 0$\;

    \tcp{第1段階：目標が通常の端点である接続を優先処理}
    \For{$i = 0$ \KwTo $2n - 1$}{
        $from \leftarrow exts[i]$\;
        $to \leftarrow$ $goals[i]$ に対応する $B$ 上の目標端点\;

        \If{$to$ が有効な端点 \textbf{and} $from$ の現在の接続相手 $\neq tar$}{
            DCJ操作を実行し，$from$ と $to$ を隣接させる\;
            $\text{DoubleCutJoin}(A, src, tar)$\;
            $c \leftarrow c + 1$\;
        }
    }

    \tcp{第2段階：目標がテロメアである接続を処理}
    \For{$i = 0$ \KwTo $2n - 1$}{
        $from \leftarrow exts[i]$\;
        $to \leftarrow$ $goals[i]$ に対応する目標 (テロメア) \;

        \If{$to$ がテロメア \textbf{and} $from$ の現在の接続相手 $\neq tar$}{
            DCJ操作を実行し，$from$ をテロメアにする\;
            $\text{DoubleCutJoin}(A, src, tar)$\;
            $c \leftarrow c + 1$\;
        }
    }
    \Return $c$\;
\end{algorithm}

\section{正当性}
本アルゴリズムの正当性は，前述の補題\ref{lem:comp_change}（成分数の変化）および補題\ref{lem:odd_path_change}（奇数長パス数の変化）から直接的に導かれる．
これらの補題により，1回のDCJ操作で $C + I/2$ が増加する最大量は $1$ であることが示されている（補題\ref{lem:lower_bound}）．

アルゴリズム2で採用している「目標の接続を順次確定させていく」という貪欲的な戦略は，
隣接グラフの観点では「長さ2のサイクル（共通の隣接）」あるいは
「長さ1のパス（共通のテロメア）」をグラフから分離独立させる操作に相当する．
この操作は，$C$ を1増加させるか，あるいは $I$ を2増加させることで，
$C + I/2$ を常に 1 ずつ増加させる効果を持つ．
したがって，各ステップごとに距離 $d_{\mathrm{DCJ}}$（(2.3)式）は $1$ ずつ減少し，
最終的に $A=B$ となるまで最短回数でのソート手順を与えることが保証される．

\section{考察}
実験結果より，メモリ使用量に関しては遺伝子数 $N$ に対して
線形増加の傾向を示しており，
$N=100,000$ の規模でも約 26 MB 程度と，
一般的なPC環境において十分に動作する範囲に収まっていることが確認できる．

実行時間について，データの読み込みを含めた場合
（表\ref{tab:benchmark_total}）は $N=100,000$ で約 20 秒を
要しているのに対し，アルゴリズム部分のみ（表\ref{tab:benchmark_algo}）
では約 0.05 秒で処理が完了している．
この乖離の主な要因は，入力処理におけるテキストデータのパース
（構文解析）にあると考えられる．
本実装では入力の容易さと可読性を重視し，
10進数のテキスト形式を採用している．
しかし，遺伝子数 $N$ が増大すると，
個々の遺伝子IDを表す文字数（桁数）も $\log_{10} N$ のオーダーで増加するため，
テキストデータの総容量およびパースにかかる時間は
$O(N \log N)$ で増加する．

厳密な計算量理論の観点に立てば，$N \to \infty$
において数値を表現するビット長自体が増大するため，
いかなる形式であれ完全な線形時間の達成は困難である．
しかし，アルゴリズムの理論解析で一般に用いられる
計算モデル（Word RAM Model）では，
マシン語長に収まる整数の操作は定数時間 $O(1)$ とみなされる．
この前提に近づけ，実用的な速度を得るためには，
本来であればバイナリ形式の採用などによる
入出力の最適化が為されるべきである．
本研究では，データ作成の簡便さとデバッグ時の可読性を優先した結果，
この入出力オーバーヘッドが残存することとなった．

一方，核心となるDCJ距離計算および操作手順生成アルゴリズムそのものは，
理論通り $O(N)$ の線形時間特性を示しており，
大規模なデータセットに対しても実用的な時間内で
解を導出可能であることが実証された．
