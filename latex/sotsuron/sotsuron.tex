% --- 論文要旨 ---
\chapter*{論文要旨}
\addcontentsline{toc}{chapter}{論文要旨}

生物学において進化の過程を論じる際、
突然変異を経て変化する世代間の影響を考慮することは不可欠である。
また、生物学的背景から発生しやすい変異と
そうでない変異を区別し、前者を中心に
遺伝的な距離を定義し、考察することは自然なアプローチと言える。

HannenhalliおよびPevzner (1995)\cite{hp1995}は、
染色体に作用する操作を「転座」「融合」「分裂」「反転」
の4種類に制限し、遺伝的距離 $d_{\mathrm{HP}}$
を定義した。しかしながら、この手法および提案された
アルゴリズムには、計算上の制約や複雑性に関する課題が存在した。

Bergeronら (2009)\cite{bergeron2009}は、これらの問題を解決すべく、
上記4種類の操作を一般化した「Double-Cut-And-Join (以下、DCJ)」
という単一の操作を導入し、新たなアルゴリズムを提案した。
DCJ操作に基づく距離を $d_{\mathrm{DCJ}}$ と呼ぶ。

Bergeronらの手法は、染色体内の特定パターンを検出することで
線形時間での操作手順出力を可能にしているが、その実装は
極めて高度であり、直感的な理解が困難な側面がある。
本論文では、DCJ理論におけるBergeronらと同様の前提条件の下、
C言語を用いたより簡潔な線形時間アルゴリズムの実装について述べる。
本稿の前半では $d_{\mathrm{DCJ}}$ の算出に特化したアルゴリズムを、
後半では操作手順も出力する、より汎用性の高いシンプルな実装を紹介する。

実装においては、一部の着想をBergeronら(2009)の研究に依拠しつつも、
主要なデータ構造および処理ロジックの大部分は独自に構築したものである。

% --- 第1章：導入 ---
\chapter{導入}

\section{背景}
計算分子生物学において遺伝的距離をモデル化する手法には
多くの変遷があるが、その基本的な枠組みは共通している。
単純性の原理 (Principle of Parsimony) のもとでは、
可能な限り小さい回数の変化を知ることが重要になる。つまり、
最終的な目標は、二つのゲノム間の最小変異回数を算出し、
それらを比較・評価することになる。

\section{ゲノムおよび染色体の表現方法}
比較対象となる二つのゲノムを、それぞれ
\textit{source} および
\textit{target} と呼ぶ。
各ゲノムは染色体 (chromosome) の集合であり、
各染色体は遺伝子 (gene) の並びである。

各遺伝子は正負の符号を持つ整数値で識別する。
向きの基準を \textit{target} ゲノムに置き、
絶対値の対応づけは任意であるため、 \textit{target}
が昇べきの順となるようにつける。すなわち、
遺伝子数 $n$ のゲノムにおいて、\textit{target}
が単一の線形染色体である場合、その表現は常に
$\langle 1 \ 2 \ \dots \ n \rangle$
と一意に定まる。線形染色体と環状染色体を区別するため、
本論文では以下の表記を用いる。
\begin{itemize}
    \item \textbf{線形染色体}: $\langle \dots \rangle$ で囲む。
    \item \textbf{環状染色体}: $( \dots )$ で囲む。
\end{itemize}

\begin{remark}
環状染色体 $( 5 \ 6 \ 7 )$ は、
要素を巡回させた $( 6 \ 7 \ 5 )$ や
 $( 7 \ 5 \ 6 )$ と同一である。
\end{remark}

\section{端点 (Extremity) と隣接 (Adjacency)}
アルゴリズムの実装においては、
遺伝子間の「接続関係」を直接扱う方が効率的である。
遺伝子 $g$ に対し、二つの \textbf{端点 (Extremity)}
 を、右側の端点 $g$ および左側の端点 $-g$ と定義する。
 二つの遺伝子の接続は、これら端点の2要素の集合として表現され、
 これを \textbf{隣接 (Adjacency)} と呼ぶ。

また、線形染色体の末端については、
特殊なシンボル $o$ を用いて
\textbf{テロメア (Telomere)} との接続
$\{o, x\}$ として扱う。この定義により、
ゲノムは単なる隣接関係の集合として記述でき、
線形・環状の区別や染色体数を意識せずに
統合的な操作が可能となる。

本研究での実装において、これらの概念は以下の構造体として定義される。

\begin{lstlisting}[caption=Extremity 構造体の定義, label=code:extremity]
typedef struct Extremity
{
    int id;                     // 遺伝子ID (1 ...)
    int sign;                   // 向き (1 or -1)
    struct Extremity *reality;  // ゲノムAにおける接続先
    struct Extremity *desire;   // ゲノムBにおける接続先
} Extremity;
\end{lstlisting}

\begin{lstlisting}[caption=Adjacency 構造体の定義, label=code:adjacency]
typedef struct Adjacency
{
    Extremity *left;            // 隣接の左端点
    Extremity *right;           // 隣接の右端点
    struct Adjacency *left_to;  // グラフ上の左側エッジ
    struct Adjacency *right_to; // グラフ上の右側エッジ
    int visited;                // 探索用フラグ
} Adjacency;
\end{lstlisting}

% --- 第2章：必要な定理 ---
\chapter{理論的背景}

\section{$d_{DCJ}$に関する等式}

Bergeronら(2006)\cite{bergeron2006}は、
DCJ操作を用いたゲノム距離の計算において、
以下の重要な定義および定理を示している。

\begin{definition}[Double-Cut-And-Join]
ゲノムの隣接関係の集合に対する操作であり、
二つの隣接 $\{u, v\}$ と $\{x, y\}$ を切断し、
新たに $\{u, x\}$ と $\{v, y\}$ 、
または $\{u, y\}$ と $\{v, x\}$
として再結合する操作を指す。
テロメア $o$ を含む隣接に対しても同様に定義される。

また、$\{o, o\}$ とのDCJも認めることで、
単なる隣接の切断もDCJに含めるものとする。
\end{definition}

\begin{definition}[隣接グラフ $AG(A,B)$]
2つのゲノム $A, B$ において、
それぞれの隣接関係およびテロメアを頂点集合とし、
共通の遺伝子端を持つ頂点間にエッジを引いたグラフを
隣接グラフと呼ぶ。
\end{definition}

\begin{remark}
それぞれの頂点の次数は高々2であるため、隣接グラフは
サイクル (Cycle) とパス (Path) のみからなる。
\end{remark}

\begin{lemma}[ゲノムの一致条件]
$N$ 個の遺伝子集合からなるゲノム $A, B$ が
$A=B$ であるための必要十分条件は、
次式が成り立つことである：
\begin{equation}
    N = C + \frac{I}{2}
\end{equation}
ここで、$C$ は隣接グラフ $AG(A,B)$
におけるサイクルの数、$I$ は奇数長パス
 (辺の数が奇数のパス) の数である。
\end{lemma}

\begin{theorem}[DCJ距離公式]
2つのゲノム $A, B$ 間の最短のDCJ操作回数 (DCJ距離)
$d_{DCJ}(A,B)$ は、次式で与えられる：
\begin{equation}
    d_{DCJ}(A,B) = N - \left( C + \frac{I}{2} \right)
\end{equation}
この距離を達成する最短の並べ替え手順は、
線形時間 $O(N)$ で計算可能である。
\end{theorem}

\section{距離公式に関する考察}
(2.2)式は、$d_{DCJ}$を計算する上で、
隣接グラフの初期状態さえ構築できれば、
実際にグラフを物理的に変形させる手順を踏まずとも、
グラフ内のコンポーネント (サイクルおよびパス) を走査し
$C, I$ を計数するだけで距離が確定することを示している。
この知見に基づき、まずアルゴリズム1を提案する。

% --- 第3章：アルゴリズム1 ---
\chapter{アルゴリズム1：距離計算の実装}

本アルゴリズムは、隣接グラフを構築し、
そこに含まれるサイクルおよび奇数長パスを線形時間で探索するものである。

\section{データ構造}
実装においては、以下の3つの要素を中核とする。
\begin{itemize}
    \item \textbf{Extremity}: 遺伝子の端点を表す構造体。IDと符号を保持する。
    \item \textbf{Adjacency}: 2つの Extremity のペア。探索を効率化するため、各隣接が $source$ と $toget$ のどちらに属するか、および訪問済みかどうかのフラグを持つ。
    \item \textbf{Map}: 特定の端点がどの Adjacency に含まれているかを定数時間で検索するための整数値配列。
\end{itemize}

\begin{algorithm}[H]
    \caption{隣接グラフを用いたDCJ距離の計算}
    \KwIn{ゲノム $A$, ゲノム $B$}
    \KwOut{DCJ距離 $d_{DCJ}$}

    $N \leftarrow$ 遺伝子数\;
    $AG(A, B) \leftarrow$ $A$ と $B$ の隣接集合から隣接グラフを構築\;
    $C \leftarrow 0$, $I \leftarrow 0$\;

    \ForEach{未訪問の隣接ノード $v \in AG(A, B)$}{
        $v$ から始まるコンポーネントをトラバースする\;
        $L \leftarrow$ トラバースしたエッジ (隣接関係) の総数\;
        \If{探索が開始点に戻った (サイクルを発見) }{
            $C \leftarrow C + 1$\;
        }
        \ElseIf{端 (テロメア) に到達した (パスを発見) }{
            \If{$L$ が奇数}{
                $I \leftarrow I + 1$\;
            }
        }
    }
    $d_{DCJ} = N - (C + I/2)$\;
    \Return $d_{DCJ}$\;
\end{algorithm}

\section{正当性と計算量}
本アルゴリズムの探索部分は、
各エッジをちょうど一度ずつ走査するため、
計算量は $O(N)$ となる。
終了性については、
各 Adjacency に訪問済みフラグを設定し、
一度の走査で全コンポーネントを網羅するため、
有限時間内での停止が保証される。

% --- 第4章：アルゴリズム2 ---
\chapter{アルゴリズム2：操作手順の出力}

\cite{bergeron2006} の理論を基に、
実際の変異手順を逐次的に出力するアルゴリズムを実装した。

\section{実装方針}
本アルゴリズムでは、
現在のゲノム状態を目標のゲノム状態へ貪欲法により近づけていく。
具体的には、特定の接続が目標とする接続となっていない場合、
DCJ操作を適用してその接続を確立させていく。

\begin{algorithm}[H]
    \caption{DCJ操作によるゲノムソート手順の生成}
    \label{alg:proceed}
    \KwIn{現在のゲノム $A$ の端点集合 $exts$, 目標状態 $goals$}
    \KwOut{実行されたDCJ操作のログ}

    $n \leftarrow$ 遺伝子数, $c \leftarrow 0$\;

    \tcp{第1段階：目標が通常の端点である接続を優先処理}
    \For{$i = 0$ \KwTo $2n - 1$}{
        $from \leftarrow exts[i]$\;
        $to \leftarrow$ $goals[i]$ に対応する $B$ 上の目標端点\;

        \If{$to$ が有効な端点 \textbf{and} $from$ の現在の接続相手 $\neq tar$}{
            DCJ操作を実行し、$from$ と $to$ を隣接させる\;
            $\text{DoubleCutJoin}(A, src, tar)$\;
            $c \leftarrow c + 1$\;
        }
    }

    \tcp{第2段階：目標がテロメアである接続を処理}
    \For{$i = 0$ \KwTo $2n - 1$}{
        $from \leftarrow exts[i]$\;
        $to \leftarrow$ $goals[i]$ に対応する目標 (テロメア) \;

        \If{$to$ がテロメア \textbf{and} $from$ の現在の接続相手 $\neq tar$}{
            DCJ操作を実行し、$from$ をテロメアにする\;
            $\text{DoubleCutJoin}(A, src, tar)$\;
            $c \leftarrow c + 1$\;
        }
    }
    \Return $c$\;
\end{algorithm}

\section{正当性}
DCJ操作が距離 $d_{DCJ}$ に与える影響について、以下の補題が知られている。
\begin{itemize}
    \item 1回のDCJ操作で増加するサイクルの数は最大で1つである。
    \item 奇数長の数は、1回のDCJ操作で $\{-2, 0, 2\}$ のいずれかの変化を示す。
    \item 1回のDCJ操作では、サイクルと奇数長パスの数が同時に変化することはない。
\end{itemize}
これらの事実に基づき、(2.2)式において $d_{DCJ}$ を常に1減少させるようなDCJ操作が各ステップで存在することが証明されている。本アルゴリズムにおける「目標の接続を一つずつ確定させる」操作は、この最短経路を辿る操作に相当する。
